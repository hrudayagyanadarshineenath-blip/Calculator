# 🧮 Calculator

A simple and user-friendly Calculator project created to practice my frontend development skills and build a small interactive web application.

The calculator performs basic mathematical operations through a clean and easy-to-use interface.

## ✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear/reset option
- Interactive calculator buttons
- Simple and responsive design
- Easy-to-use interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
